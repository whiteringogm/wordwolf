# AI Word Wolf Relay

3つのAIチャットでワードウルフを遊ぶときの、人間側の中継作業を軽くするブラウザツールです。

## できること

- 3人のAIと2種類の秘密ワードを設定
- 少数派をランダムまたは指定で決定
- 各ターン用のプロンプトを自動生成
- AIの返答から共有発言とGMメモを分離
- 共有発言だけを次のAIへの文脈に利用
- 手掛かり → 相互質問 → 独立判定 → 反論 → 秘密投票を進行
- ゲーム状態をブラウザの localStorage に保存
- ゲームログをJSONで書き出し

## データ

外部APIは使用しません。入力した参加者名、ワード、会話ログは、このページを開いたブラウザの localStorage に保存されます。

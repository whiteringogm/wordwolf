# AI Word Wolf Relay

3つのAIチャットでワードウルフを遊ぶときの、人間側の中継作業を軽くするブラウザツールです。

## できること

- 3人のAIと2種類の秘密ワードを設定
- カテゴリ別のお題プリセット、ランダム選択、多数派 / 少数派の入れ替え
- 少数派をランダムまたは指定で決定
- 準備確認なしで、最初の手掛かりから開始
- 各ターン用の送信文面を自動生成し、その場で編集
- AIの返答を `<share>` と `<gm>` に分離して編集
- タグが消えにくいよう、AI側にはコードブロック内での出力を指定
- 回答と次の相手への質問が連続する手番を1ターンに統合
- 少数派だと推測したAIには、勝利のための擬態・ブラフを明示的に許可
- 本当の陣営推理や擬態方針はGMメモにのみ記録
- 手掛かり → 相互質問 → 推理・主張 → 反論 → 秘密投票を進行
- ゲーム状態をブラウザの localStorage に保存
- 最終結果をワンタップでコピー
- GMメモを含む全ログをコードブロック形式でコピー
- 生データをJSONで書き出し

## データ

外部APIは使用しません。入力した参加者名、ワード、会話ログは、このページを開いたブラウザの localStorage に保存されます。
